# Heartfelt Gold player guide notes

Open `index.html` locally, or use the published guide at https://trinsic64.github.io/Heartfelt-Gold/. The two HTML pages include their sprites, styles, and code. Rematches have a separate page; bonus battles stay with story trainers.

The trainer, wild encounter, shop, and evolution tables reflect the current authoring data used for this guide. Ground pickups come from the named Release-v2 event extraction and hidden item parameter table. Two visible pickup objects have unresolved item identities. Static encounter parent areas are traced through direct inbound warps; script and placement data do not by themselves establish reachability or unlock conditions. The currently released patch has not been independently checked against every table.

See `Release-v22-Item-Audit.md` for the item audit. `Item-Locations.csv` is the older Retiled Expansion item list and remains historical. Form-specific encounter rows and evolution icons were resolved against engine species IDs.
