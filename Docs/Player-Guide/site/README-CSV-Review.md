# Heartfelt Gold player guide notes — v1.0.12

Open `index.html` locally, or use the published guide at https://trinsic64.github.io/Heartfelt-Gold/. The two HTML pages include their sprites, styles, and code. Rematches have a separate page; bonus battles stay with story trainers. The first Elite Four and Champion run follows eight badges, while the second run and its bonus battles follow Gym #16 Blue.

This guide is bundled with the v1.0.12 patch named in `release.json`. The patch was decoded against the documented clean USA ROM and matched the recorded hg-engine build hash.

The trainer, wild encounter, shop, and evolution tables reflect the source data used for the v23 hg-engine build. Twenty-one player-facing trainer parties changed since v1.0.11; internal dummy Trainer 0 is omitted. Cherrygrove Mart now stocks Cherish Ball, and both Frillish forms evolve at level 40. Wild held items match the updated `HG-Engine/data/Species.c` snapshot, including form-specific rows. Ground pickups come from the named Release-v2 event extraction and hidden item parameter table. Two visible pickup objects have unresolved item identities. The 89 static encounter rows use v22 Test levels and follow the reviewed Markdown guide; the unbound Union Cave Victini command is excluded. Parent areas are traced through inbound warps or bound same-map event objects; script and placement data do not by themselves establish reachability or unlock conditions. Individual guide rows have not all been independently checked against gameplay.

See `Release-v22-Item-Audit.md` for the item audit. `Item-Locations.csv` is the older Retiled Expansion item list and remains historical. Form-specific encounter rows and evolution icons were resolved against engine species IDs. The v23 input fixed Diglett's Cave map matrix 2 by adding map member 976; those map archives were preserved byte for byte in the built ROM.
